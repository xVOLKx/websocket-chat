## <img src="images/install.svg" width="24"> Как запустить локально

1. Установи [Node.js](https://nodejs.org/).

2. Склонируй репозиторий:
   ```bash
     git clone https://github.com/xVOLKx/websocket-chat.git
     cd websocket-chat
   ```
3. Установи зависимости:
   ```bash
     npm install
   ```
4. Запусти сервер:
   ```bash
     node server.js
   ```
5. Открой в браузере: http://localhost:3000
